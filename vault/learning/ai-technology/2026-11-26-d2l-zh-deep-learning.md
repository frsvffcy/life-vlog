# 動手學深度學習：中文深度學習教材

## 摘要

[《動手學深度學習》](https://zh.d2l.ai/) 是一套結合理論、公式、圖示與可執行程式碼的深度學習教材，從預備數學與資料操作，逐步介紹神經網路及其在電腦視覺、自然語言處理等領域的應用。教材面向中文讀者，並提供程式碼與課程資源。

## 學習方式與內容

- 從資料操作、線性代數、微積分、自動微分與機率等預備知識開始。
- 透過章節中的 Jupyter Notebook 閱讀、執行及修改範例。
- 同一主題常提供從零實作與使用深度學習框架的簡潔實作，便於對照原理與工具。
- 主要內容涵蓋線性神經網路、多層感知機、卷積神經網路、循環神經網路、注意力機制與 Transformer、最佳化、電腦視覺及自然語言處理。
- 專案列有 PyTorch、NumPy/MXNet、TensorFlow 與 PaddlePaddle 等實作版本；實際章節與框架支援請以線上教材為準。

適合希望循序學習深度學習並透過程式實作驗證概念的讀者。教材包含數學推導與 Python 程式，具備基本 Python 程式設計及數學背景會較容易跟上。
