# Microsoft AI Agents for Beginners：AI 代理開發入門課程

## 摘要

[AI郵報的 18 堂課懶人包](https://www.aiposthub.com/microsoft-ai-agents-for-beginners-18-lessons-guide/)介紹 Microsoft 開源課程 [AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners)，整理課程地圖、環境設定及實作重點。本文是第三方導讀；課程內容與範例以 Microsoft 官方倉庫為準。

## 課程內容與學習方式

官方課程包含 18 堂，涵蓋：

- Agent 基礎、框架探索、設計模式與工具使用。
- Agentic RAG、可信任 Agent、規劃、多代理與後設認知。
- 生產環境、MCP／A2A／NLWeb 等協議、上下文工程與記憶管理。
- Microsoft Agent Framework、電腦操作 Agent、可擴展部署、本機 Agent 與安全防護。

每堂課提供書面教材與 Python 程式範例，部分課程並附影片。官方範例主要使用 Microsoft Agent Framework 與 Microsoft Foundry Agent Service V2；官方 README 亦指出部分範例支援 OpenAI 相容的替代服務。雲端範例可能需要 Azure 帳號，實際需求請依各課程設定說明確認。

官方提供由 Co-op Translator 維護的繁體中文（台灣）版本。官方同時提醒翻譯可能有誤，重要資訊應對照英文原文。

## 適合讀者

適合想建立 AI Agent 開發全貌，並透過程式範例理解設計模式的學習者。課程名稱中的「初學者」主要指剛開始接觸 Agent 開發；具備基本 Python、Git 與環境設定經驗會較容易完成實作。
