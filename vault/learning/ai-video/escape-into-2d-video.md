# 從寫實荷塘逃進二維手繪世界

@more.yu_ 分享「現實逃逸」影片版：木船從寫實荷塘出發，隨著船前進，身後世界逐漸變成水彩、鉛筆紋理與黑白線稿。轉換跟隨木船移動，而不是整個畫面同時套用濾鏡。[Threads 原貼文與示範影片](https://www.threads.com/@more.yu_/post/DeN_L6IkzrL)

作者稱主貼文的示範影片為 6 秒；下列提示詞則規劃 10 秒直式影片。

```text
10秒完整视频提示词｜《Escape Into 2D》
以上传图片作为唯一场景与构图参考。保持原图中的巨型荷叶、阳光、水体、水下鱼群、中央木船，以及右下方白色纸张与黑色线稿植物区域。10 seconds，vertical，一镜到底，无切镜。
核心表达：ESCAPE FROM REALITY → INTO A 2D HAND-DRAWN WORLD
0–2秒｜现实世界：从原图开始，超低位水面视角。阳光穿过巨大荷叶形成强烈星芒，水面闪烁，水下鱼群缓慢游动，水草轻轻摆动。中央木船缓慢向右下方驶去。整个彩色世界保持 bright, vivid, dimensional, alive。先让观众相信这是一个完整、真实、有空间纵深的世界。
2–4秒｜发现出口：镜头轻微跟随木船向右下方移动，木船靠近"彩色现实世界 / 白色纸张世界"之间的不规则边界。边界附近出现异常：水面反光减弱，蓝绿色水体像颜料一样向纸面晕开；几条鱼靠近边界时，身体从真实鱼类变成 watercolor fish → pencil sketch fish。船保持真实材质。让观众看到"这个地方可以逃出去"。
```

### 第 2 段

[Threads 作者回覆 2](https://www.threads.com/@more.yu_/post/DeN_V85FaTE)

```text
4–6秒｜现实开始瓦解：木船继续向右下方加速，转换沿着木船轨迹向后扩散。真实水体：photorealistic water → watercolor pigment → pencil texture → black ink line art。荷叶倒影失去颜色，水草变成墨线，鱼群变成手绘线稿。关键：不是整个画面一起变，而是一块正在扩大的"二维区域"逐渐吞掉木船身后的现实世界。
6–8秒｜跨越二维边界（全片高潮）：木船正式穿过不规则白色边缘。船头最先二维化：木纹、阴影、反光消失，变成简单黑色铅笔线；随后船身、船尾；船上人物同步变化：3D character → watercolor figure → pencil sketch → minimal line-art character。整个变化必须从前往后连续发生，不能瞬间切换，形成明显的 3D → 2D dimensional collapse。
8–9.5秒｜彻底逃离现实：木船完全变成二维手绘，镜头跟随进入右下方白色纸张区域。周围只剩黑色水流线、线稿荷叶、纤细植物枝干、少量飘落叶片。
```

## 提示詞重點

- **場景與鏡頭**：以上傳圖片作唯一場景與構圖參考；直式、一鏡到底，低位水面視角。
- **轉換順序**：寫實 → 水彩 → 鉛筆紋理 → 黑色墨線 → 純二維手繪。
- **轉換方式**：跟隨木船的運動擴散，船頭、船身、船尾與人物依序變化。
- **聲音**：水聲與風聲逐漸轉為鉛筆、紙張聲，最後趨近安靜。
- **避免**：突然切鏡、木船瞬移、新增人物、全畫面瞬間漫畫化與二維區域出現真實 3D 陰影。
