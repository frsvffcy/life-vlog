# PII Guard：台灣繁中文件的可逆個資去識別化

## 摘要

[PII Guard](https://github.com/danyuchn/pii-guard) 是面向台灣繁體中文文件的本機個資去識別化工具。它將姓名、電話、身分證字號、統編等資訊換成代號，另存本機對照資料；文件交由 AI 處理後，可將代號還原。專案採 MIT 授權，提供 CLI、本機網頁介面及 Claude Code Skill。

## 運作方式與適用情境

- 以 Presidio、CKIP 中文辨識及台灣格式規則偵測個資，再由程式替換與還原；README 表示核心快速模式不需啟動 Ollama。
- 可在本機瀏覽器人工補遮漏網內容或放回誤遮文字；Ollama 本地模型稽核是選用的加強模式。
- 適合逐份處理繁體中文文件並產生可留存的去識別化副本；不是自動攔截所有雲端 AI 請求或大量處理文件的 gateway。
- README 標示主要支援 macOS 與 Linux；Windows 可用核心流程，但 Ollama 加強模式不可用。首次執行會下載約 500 MB 的 CKIP BERT 模型。

## 隱私與限制

- **偵測不是零漏網保證：**個資偵測可能漏遮或誤遮，應人工檢查去識別化結果。工具主要處理可識別個人的資訊，不會因此去除金額、病情、合約條款等其他敏感內容；不可單憑輸出便認定文件適合公開。
- **Skill 不是作業系統安全邊界：**專案設計上避免主 agent 在一般工作流程中讀取原文與對照表，但原始檔及對照表仍由同一使用者帳號持有，不能防止同一帳號直接讀取。
- **格式範圍有限：**掃描型／圖片型 PDF 與 OCR 尚未支援。README 也提醒 DOCX／XLSX 的頁首頁尾、儲存格註解、工作表名稱與文件屬性等欄位可能不在偵測或遮蔽範圍；使用前須核對格式限制並檢查輸出。
- **效能與準確率證據：**README 提供可重跑的合成測試語料，並描述另有不公開的真實文件測試結果；作者指出合成語料可能高估真實表現，且真實測試不可由外部重現，這些結果不能視為合規證明。

## 安裝與來源狀態

- 需 Python 3.13（README 表示 3.11 以上可執行）及 `uv`；Ollama 只供加強稽核與相關 Skill 使用。
- GitHub 授權標示 MIT；模型與相依套件仍應各自遵循其授權條款。
