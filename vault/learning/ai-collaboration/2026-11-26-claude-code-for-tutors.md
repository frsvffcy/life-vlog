# Claude Code for Tutors：教師的 AI 助理實戰課程

## 摘要

[Claude Code for Tutors](https://github.com/danyuchn/claude-code-for-tutors) 是一套繁體中文互動式實戰課程，面向沒有程式背景的教師。學員在 AI 助理帶領下完成教學相關工作，藉此學習如何與 AI 協作；主線 24 堂、選修 3 堂，README 標示全程約 8.9 小時。這不是以觀看影片或簡報為主的課程。

## 課程內容

- **AI 協作：**拆解複雜需求、診斷問題、在 AI 停頓或碰到能力限制時介入。
- **教師日常：**整理成績與資料、撰寫個人化家長信、管理教材、設計練習題。
- **分析與自動化：**比較不同格式資料、建立可重複使用的工作流程與知識庫。
- **實作產出：**製作教學視覺規格、簡單班級小工具，以及個人 AI 協作設定。
- **選修：**實際生成圖片、使用 GitHub 管理版本，以及將小工具發布到網路。

## 開始方式與費用

- GitHub 專案可下載 ZIP；README 的詳細桌面版步驟是使用 Claude 桌面版的 Code 分頁，並標示需要 Claude Pro 以上方案。
- 另提供 Claude Code 終端機安裝方式。
- README 開頭提及 Claude 或 ChatGPT 桌面版，但具體課程入口使用 Claude Code 的 `.claude/skills` 與 slash commands；ChatGPT 相容性未在操作指引中明確說明，不宜直接假設所有功能都適用。
- 選修生圖課使用 Gemini API，可能產生費用；其他選修也要求 GitHub 帳號、相關工具安裝或公開發布網站。

## 隱私與授權提醒

- 課程素材採用虛構教師與學生情境；若自行改用真實學生資料，先確認校方規範與所用 AI 工具的資料處理方式，不要未經核准提供可識別的學生資訊。
- 網站發布課程會將工具放到公開網址；發布前須去識別化，並確認輸出內容不含個人資料。
- README 稱課程免費開源；專案的 `LICENSE` 實際採 **CC BY-NC-ND 4.0**，要求署名、禁止商業使用，且不得散布改作版本。這些限制不同於一般允許自由改作的開源授權；分享或改編前應查看授權全文。
